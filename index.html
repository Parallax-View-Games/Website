About me

I am an australian game developer who make games for fun. I won't act like these games are perfect. I'm still a teenager who is still learning but, I wanted to share these projects and games that I make. The name, "Parallax View Games", is meant to show how I see things differently. And because I see things differently, I make things differently.

How I make games

I make games in a confusing way but I feel like the result is the only thing that matters. There are three main parts to how I make games after coming up with the idea. Part 1 is coding the game. I use a modded version of scratch known as turbowarp to code the game. Then I use the built-in packager to turn it into a html file. Part 2 is compiling the game into a mobile or computer app. For this, I use electron which is a tool that lets me turn the html file into and apk or exe file. The final part is distributing the game. I simply put the game on itch.io and add a page to my website about the game.

The why

You know who is making the games and how I'm making the games, I will now tell you why I make games like this and why I'm making them at all. I am using turbowarp because of how beginner friendly it is and because it has many tools and extensions built in that allow me to turn these projects into apps. I use electron because it is one of the only ways to compile these games into apps but I also use it because it allows me to save data locally. I use itch.io because its a lot easier to publish games on it and other stores like steam or the google play store charge a pricey fee to publish games. Finally, I make games because they're the only form of media that allow me to explore all of my ideas and stories. My message to everyone is that you can make games, you don't need to be good at coding, you don't need to know any programming languages, you just need to give it a shot.
